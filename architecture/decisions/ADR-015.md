# ADR-015: Use `gemini-3.5-flash-lite` on the free tier

- **Status:** Accepted. Supersedes the model id in ADR-014.
- **Date:** 2026-11-20

## Context

The key is on the Gemini free tier. Billing is not enabled, so there is no dollar spend to cap. The provider quota is the hard limit.

ADR-014 pointed every role at `gemini-3.8-flash` after `gemini-2.5-flash` returned HTTP 404. [Actions run 44694606771](https://github.com/Anilkumark17/tinydb/actions/runs/44694606771) reached the analyst on that id and was cancelled while the call was still running. A direct `generateContent` check from this machine then showed:

- `gemini-3.8-flash` and `gemini-3.5-flash` did not return within 25 seconds.
- `gemini-3.1-pro-preview` returns HTTP 429. The free tier has no Pro quota.
- `gemini-3.5-flash-lite` and `gemini-3.1-flash-lite` both returned a short completion immediately.

A model that does not answer inside the 20-minute analyst job cannot finish a run, and a Pro id cannot be the reviewer on this key.

## Decision

`autose/__init__.py` sets both `FLASH` and `PRO` to `gemini-3.5-flash-lite`. One run is started after this change. No second run is started while that one is in progress.

The reviewer remains a separate job, prompt, and token, as in ADR-008. The model id is not what separates it.

## Alternatives considered

Stay on `gemini-3.8-flash` and raise the job timeout. The free-tier call did not return in a direct check, and the Actions job had already used most of its 20 minutes. A longer timeout would spend more of the daily quota on a call that may not finish.

Enable billing and call Pro. That leaves the free tier. The project stays on the free quota.

Use `gemini-3.1-flash-lite`. It also answered. `gemini-3.5-flash-lite` is the newer of the two that answered, so that is the one the runner calls.

## Consequences

The reviewer shares the lite model's blind spots. A wrong approval is still possible. The verdict script and the maintainer remain the checks after the model.

If `gemini-3.5-flash-lite` returns 429, the run stops and this ADR should be superseded with whichever lite id still has quota. It should not be edited in place.
