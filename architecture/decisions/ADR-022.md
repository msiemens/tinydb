# ADR-022: A reviewer-only workflow for seeded checks and model comparison

- **Status:** Accepted.
- **Date:** 2026-11-21

## Context

Every role in `autose.yml` uses the same model (ADR-015), and the reviewer approved PR #22, which does not fix issue #2. Five seeded diffs with ground-truth labels existed in `experiment/seeded_prs/`, but none had been opened as a pull request or shown to the reviewer, so there was no measure of what the reviewer catches.

## Decision

`.github/workflows/review-check.yml` runs only the reviewer stage. It reads a list of targets from `experiment/review_check/matrix.json`: pull request, branch, issue, seeded label, model. For each target it checks out the harness and the pull request branch separately, so the reviewer code is the same for every target. It runs the reviewer with the same prompt, tools and verdict check as `autose.yml`, with no GitHub token in the model step. It then prints a result line, writes a step summary, posts the review on the pull request, and uploads the review and usage log.

`AUTOSE_REVIEWER_MODEL` sets the reviewer model for that run only. A model named `groq:<id>` goes straight to Groq. `AUTOSE_NO_FALLBACK=1` turns off the ADR-017/018 fallback, so each verdict comes from the named model. `autose.yml` sets neither, so the workflow itself is unchanged.

The workflow runs on a push to `review-check/**` or by hand. `usage-total.yml` downloads the usage logs of the runs listed in `results/` and sums them.

## Alternatives considered

Open the seeded PRs and let `autose.yml` review them. The workflow reviews only the branch it built for an issue, so it cannot review a seeded diff.

Compare against a stronger model. The free-tier key has no Pro quota (ADR-015), and Groq's free tier allows 8,000 tokens per minute, which one review exceeds.

## Consequences

Results are in `results/reviewer_check.md`. Seeded PRs #30 to #34 stay open, marked not for merge.

The comparison covers two Gemini lite models only. Groq produced no verdicts on the free tier.
